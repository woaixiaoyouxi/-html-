📅 时间轴日程管理器 · 双指缩放 · 分享链接备份

一个轻量、可离线的周日程管理器，纯前端 HTML 单文件，无需服务器，直接打开浏览器即可使用。支持双指缩放时间轴、今日高亮、自动清理旧事件、可调列宽、拖拽创建/编辑/删除事件，以及一键导出为分享链接（包含全部数据，接收方打开即还原）。

可以把网页添加到桌面或者收藏会更加便捷



📸 功能预览

时间轴视图：以小时为单位显示日程（06:00~23:00），分为缩放模式和一般模式。

周切换：前后周导航，数据自动保存。

今日高亮：自动识别当天日期，列背景和标题特殊标记。

可调列宽：拖拽日历列边缘的蓝色手柄调整各列宽度。

事件操作：

拖拽创建：在任意日期的任意区域按住并拖动，松开后自动创建时间段，弹出编辑框。

点击编辑：点击事件块修改备注、颜色、标签。

右键/长按删除：在桌面端右键点击事件，或在移动端长按事件（600ms）可快速删除。

堆叠布局：当同一时间段有多个事件时，自动分列堆叠显示，避免遮挡。

颜色与标签：预设 10 种颜色，可自定义默认颜色；每个事件支持一个短标签。

过滤视图：可选择只显示某一天（周一至周日）的事件，方便专注。

浮动时间指示器：拖拽创建时显示当前时间的浮动提示，精确到分钟。



🔐 数据持久化与迁移

本地存储：所有数据（包含每周事件、列宽、缩放高度）自动保存到浏览器 localStorage，无网络依赖，清空浏览器缓存即可删除数据。

分享链接：点击工具栏的 “分享链接” 按钮，一键复制包含全部数据的 URL。任何人在浏览器中打开该链接，将自动加载并还原你的完整日程（包括所有周、列宽、缩放设置）。

导入/导出 JSON：支持导出原始 JSON 数据备份，或从 JSON 文本导入恢复（含版本号，未来可兼容升级）。

版本兼容：导出数据包含 version 字段，结构变化时可安全迁移。



🖥 使用方式

直接下载 schedule.html 或复制仓库代码到一个 HTML 文件。

用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开该文件。

所有操作都在页面上完成，无需安装、无需联网。



🎮 交互说明

操作	桌面端	移动端
